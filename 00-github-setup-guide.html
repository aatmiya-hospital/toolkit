GitHub Setup — Aatmiya Toolkit Hosting
One-time setup · No technical background needed · ~20 minutes
What this sets up
GitHub is a free website that stores files and makes them accessible via a web link. Once set up, every tool we build gets a permanent link — patients can open it on their phone, you can use it on the OPD tablet, and everything stays free forever. You just drag and drop files to update.
✓ Free forever ✓ No coding needed to maintain ✓ No patient data stored online ✓ Custom domain later
1
Create your GitHub account
~3 minutes · One time only
1
Go to github.com
Open github.com in any browser. Click the green "Sign up" button.
2
Choose your username
Use something like aatmiya-hospital or dhaivat-mehta. This becomes part of your web address:
https://aatmiya-hospital.github.io/toolkit
Choose a professional username — it appears in every tool's URL.
3
Verify email and choose Free plan
GitHub will ask you to verify your email. When asked about a plan, choose Free. Everything we need is on the free plan.
2
Create the toolkit repository
A repository is just a folder on GitHub that holds your files
1
Click "New repository"
After logging in, click the + icon (top right) → New repository.
2
Fill in the details exactly as follows
Repository name: toolkit
Description: Aatmiya Hospital clinical tools
Visibility: ✓ Public (required for free hosting)
Add README: ✓ Check this box
The repository name must be toolkit (all lowercase) for the URLs to work correctly.
3
Click "Create repository"
You'll land on a page showing your new repository. It'll look mostly empty — that's fine.
3
Enable GitHub Pages (the free web hosting)
This turns your file folder into a live website
1
Go to Settings
Inside your repository, click the Settings tab (the last tab in the row, with a gear icon).
2
Find the Pages section
In the left sidebar, scroll down and click Pages.
3
Set source to "main" branch
Under Source, click the dropdown and select main. Leave folder as / (root). Click Save.
Wait 2–3 minutes. GitHub will show a green box: "Your site is published at https://[your-username].github.io/toolkit". That's your permanent link.
4
Upload your HTML tool files
This is how you add tools — same process every time, no coding
1
Go back to the repository main page
Click your repository name at the top. You'll see the list of files (currently just README.md).
2
Click "Add file" → "Upload files"
You'll see a large drag-and-drop area.
3
Drag your HTML files here
Drag all the tool .html files from your downloads folder into this area. You can upload multiple files at once.

After uploading, scroll down and click "Commit changes" (this is GitHub's word for "save").
Each tool will be live at: https://[username].github.io/toolkit/01-feelings-wheel.html
4
Create the index page (tool menu)
We will build a central home page (index.html) that lists all tools with descriptions and links. This becomes the main URL patients and staff bookmark. Claude will generate this file automatically once more tools are ready.
5
Recommended file structure
How to organise as the toolkit grows
→
toolkit/ ← your GitHub repository root ├── index.html ← home page / tool menu │ ├── clinical/ ← clinician-only tools │ ├── 03-cows-ciwa.html │ ├── 04-soap-note.html │ ├── 05-case-formulation.html │ └── 06-treatment-plan.html │ ├── patient/ ← patient-facing tools │ ├── 01-feelings-wheel.html │ ├── 02-breathing-timer.html │ ├── 07-safety-plan.html │ └── 08-mood-checkin.html │ ├── de-addiction/ │ ├── 09-readiness-ruler.html │ └── 10-craving-chain.html │ └── corporate/ ← wellness AMC tools ├── 11-burnout-screener.html └── 12-stress-assessment.html
To create folders on GitHub: when uploading, type the folder name followed by "/" in the filename field — GitHub creates the folder automatically. E.g., type patient/01-feelings-wheel.html.
6
How to update tools in future
Same 3-step process every time
1
Download the updated file from Claude
When Claude builds you a new or updated tool, download the .html file to your computer.
2
Go to the file on GitHub and click the pencil/upload icon
Navigate to the file in your repository → click the pencil (edit) icon if editing, or use "Add file → Upload files" for new files.
3
Upload and click "Commit changes"
GitHub deploys the update automatically within 1–2 minutes. The live URL never changes — anyone who bookmarked it gets the latest version.
Bookmark your repository page: github.com/[your-username]/toolkit — you'll visit this every time you want to update a file.
7
Optional later: Custom domain
tools.aatmiyahospital.com instead of username.github.io/toolkit — ~₹700/year
→
When you're ready, buy a .com or .in domain from GoDaddy India or BigRock (~₹700–₹900/year). Then in GitHub Pages Settings, enter your custom domain and follow the DNS instructions (Claude can walk you through this step-by-step when needed). The toolkit stays free — you only pay for the domain name.
Suggested domain: tools.aatmiyahospital.com or aatmiyatools.in
